# Release Checklist

## Purpose

Use this checklist before publishing a release.

## Review

- [ ] Scope is approved.
- [ ] Human review is complete.
- [ ] Required documentation is updated.
- [ ] Known limitations are documented.

## Quality

- [ ] Install check completed.
- [ ] Lint check completed.
- [ ] Test check completed.
- [ ] Production build check completed.
- [ ] UI review completed where applicable.

## Compatibility

- [ ] Fineract compatibility reviewed.
- [ ] Tenant behavior reviewed.
- [ ] Permission behavior reviewed.
- [ ] Existing workflows reviewed.

## Configuration

- [ ] Runtime configuration reviewed.
- [ ] Feature flags reviewed.
- [ ] Branding reviewed where applicable.
- [ ] Localization reviewed where applicable.

## Release Notes

- [ ] Summary prepared.
- [ ] Changes listed.
- [ ] Limitations listed.
- [ ] Follow-up items listed.
