# Shell Branding Scope

This scope exists to keep PR #21 documentation-only and to prevent unsafe broad renaming.

## Included In Future UI Patches

- Visible copy displayed to end users.
- Accessibility labels where the product name appears.
- Browser or app metadata where safe.

## Excluded From Branding Patches

- `mifosx-*` Angular selectors.
- Existing package names.
- API identifiers.
- Permission names.
- Environment variables.
- Documentation links that intentionally point to inherited upstream community resources.
