# Decision Memory

## Purpose

Record stable decisions that agents should not rediscover repeatedly.

## Decisions

## D-001: Keep Angular

The repository remains Angular-based. Do not propose a React or full frontend rewrite for MCOP work.

## D-002: Fineract Remains System of Record

Apache Fineract remains the system of record for core financial operations.

## D-003: MCOP Is Not the Universal Platform

This repository is the MifosX/Fineract provider portal. Universal multi-CBS platform engines belong in a separate future repository.

## D-004: RiskOps Lite Is Explainable First

RiskOps Lite starts with explainable, source-linked indicators.

## D-005: AI Copilot Is Read-Only First

The first AI Copilot scope is explanation, search, help, and guidance only.
