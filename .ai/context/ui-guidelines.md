# UI Guidelines Context

## UI Direction

MCOP should be practical, clean, dense enough for operations, and readable for branch users.

## Rules

- Use Angular Material patterns already present in the repository.
- Prefer clarity over fancy visuals.
- Important status must not rely on color only.
- Use badges, labels, and clear text for risk states.
- Keep dashboards fast and scannable.
- Include loading, empty, and error states.
- Avoid large custom visual systems unless approved.

## Dashboard Style

Dashboard widgets should be operationally useful:

- KPI card.
- Summary table.
- Risk signal card.
- Filter panel.
- Drill-down link.

## Accessibility

Use clear labels, readable contrast, and keyboard-friendly controls where practical.
