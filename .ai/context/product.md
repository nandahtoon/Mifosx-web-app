# Product Context

## Product Name

MifosX Commercial Operations Portal (MCOP)

## Product Role

MCOP is a commercial operations portal for Apache Fineract and MifosX-based financial institutions.

It improves user productivity, dashboard visibility, operational control, and explainable risk visibility.

## Repository Boundary

This repository is not the future Universal Financial Operations Platform.

It should stay focused on Fineract/MifosX operations.

## Main Users

- Executive user.
- Branch manager.
- Loan officer.
- Teller or cashier.
- Risk officer.
- Operations manager.
- System administrator.

## Product Direction

- Modern dashboard.
- Client 360.
- Loan 360.
- Collection workspace.
- RiskOps Lite.
- Read-only AI Copilot UI.
- Tenant branding.
- Feature flag UI.
- Better task and approval visibility.

## Product Rule

Every feature should be reusable across institutions and should not create a customer-specific frontend fork.
