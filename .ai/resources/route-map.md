# Route Map Resource

## Purpose

This file helps agents reason about route impact before changing navigation or feature modules.

## Current Guidance

Use existing Angular routing modules and lazy-loaded feature modules.

Before adding a new route, check:

- Existing route path.
- Existing resolver pattern.
- Permission expectations.
- Navigation menu impact.
- Breadcrumb or page title behavior.

## Important Areas

- Clients.
- Groups.
- Centers.
- Loans.
- Savings.
- Accounting.
- Reports.
- Organization.
- System.
- Checker inbox and tasks.
- Dashboard or home route.

## Rule

Do not move or rename existing core routes without explicit approval.
