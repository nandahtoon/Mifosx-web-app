# Playbook: Bug Fix

## Goal

Fix one defect with the smallest safe change.

## Steps

1. Reproduce or describe the issue.
2. Identify affected route, component, or service.
3. Check whether existing tests cover the behavior.
4. Make the smallest focused change.
5. Avoid unrelated refactoring.
6. Add or update test where practical.
7. Run checks or explain why not.

## Report

- Root cause.
- Files changed.
- User impact.
- Checks run.
- Known limitations.
