# Angular Skill

## Purpose

Use this skill when changing Angular modules, components, services, routing, or templates.

## Rules

- Reuse existing Angular patterns.
- Keep API calls inside services.
- Keep presentation components input-driven where practical.
- Use Angular Material components already used in the project.
- Use RxJS patterns consistent with existing code.
- Avoid new dependencies unless approved.
- Avoid unrelated formatting changes.

## Checklist

- [ ] Correct module selected.
- [ ] Service created or reused.
- [ ] Component has loading state.
- [ ] Component has empty state.
- [ ] Component has error state.
- [ ] Existing routes still work.
- [ ] Build command considered.
