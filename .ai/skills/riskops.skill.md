# RiskOps Skill

## Purpose

Use this skill when creating or reviewing RiskOps Lite features.

## Rules

- Keep RiskOps Lite explainable.
- Start with deterministic indicators.
- Link risk signals to source data where practical.
- Do not perform financial actions.
- Do not create black-box decision behavior.

## Example Signals

- Overdue concentration.
- Restructure watchlist.
- Renewal watchlist.
- Branch risk summary.
- Field officer risk summary.
- PAR summary.

## Checklist

- [ ] Signal is explainable.
- [ ] Source data is identified.
- [ ] User action is review-oriented.
- [ ] No workflow mutation introduced.
- [ ] Empty/error states included.
